## Project Overview
This project demonstrates the setup of an AWS Control Tower Landing Zone for a new organisation.

## AWS Services Used
- AWS Control Tower
- AWS Organizations
- AWS IAM Identity Center
- AWS Config
- AWS Accounts
- Organizational Units (OUs)

## Organizational Units
- Security OU
- Sandbox OU

## Objective
To create a secure, governed, and centrally managed multi-account AWS environment using AWS Control Tower.

## Key Features
- Centralized account management
- Organizational Unit structure
- Security and governance controls
- Automated compliance monitoring
- Centralized identity management

## Architecture
The project uses AWS Control Tower to establish a governed multi-account AWS environment.

## Project Status
AWS Control Tower Landing Zone configuration and organizational structure were designed and configured as part of this project.
